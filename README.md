# Tastes of Africa

A multi-page website celebrating the rich culinary traditions of Africa,
built with HTML, CSS, and vanilla JavaScript.

## Tech Stack

- HTML5
- CSS3
- JavaScript (DOM)

## Run Locally

1. Clone the repository:

   git clone https://github.com/V-Mugisha/taste_of_africa_website_project.git

2. Navigate into the project folder:

   cd taste_of_africa_website_project

3. Open `index.html` in your browser (double-click the file, or run
   `open index.html` / `xdg-open index.html` from the terminal).
